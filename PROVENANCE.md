# Source provenance

## Public tree decision

Every executable source file in this repository was written for this clean release
tree on 2026-08-24. It uses Python and POSIX/OpenWrt interfaces from their public
documentation. No source file, generated bytecode, wheel, firmware asset, runtime
state, or deployment configuration was copied from the private router workspace.

| Public path | Origin | License decision |
|---|---|---|
| `src/lan_music_bridge/` | New implementation for this repository | Apache-2.0 |
| `tests/` | New synthetic tests for this repository | Apache-2.0 |
| `scripts/`, `packaging/` | New packaging and audit files | Apache-2.0 |
| Documentation and examples | New, synthetic, no household facts | Apache-2.0 |
| `LICENSE` | Apache License 2.0 standard text | Apache-2.0 |

## Explicit exclusions

The private workspace contained mature endpoints, device-specific local-library
logic, deployment scripts, state formats, third-party resolver packages, binary
wheels, generated bytecode, and operating evidence. Those materials had no complete
public provenance/license chain and included private deployment assumptions. They
were used only to identify product requirements and risk boundaries; none entered
this tree.

Provider-specific resolution and renderer-disk publishing remain external adapter
work. An adapter must carry its own provenance, dependency notices, and compatible
license before it can be distributed.
